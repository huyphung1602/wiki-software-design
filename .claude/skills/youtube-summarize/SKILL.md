# YouTube Video Summarizer

Summarize YouTube videos into structured markdown notes saved to the notes vault.

## Configuration

- **Output directory**: `/Users/huyphung/workspace/notes/ai-content/`
- **Filename format**: `YYYYMMDD-slug.md` (e.g., `20260329-ai-native-engineer.md`)
- **Tags style**: lowercase, single-word or hyphenated (e.g., `machine-learning`, `productivity`)

## When to Use This Skill

Activate when the user:
- Asks to summarize a YouTube video
- Provides a YouTube URL and wants notes/summary
- Invokes `/youtube-summarize <url>`

## Workflow

### Step 1: Extract Video Metadata

Run this command to get the video title, channel, and duration:

```bash
yt-dlp --print "%(title)s|||%(channel)s|||%(duration_string)s" "YOUTUBE_URL"
```

If yt-dlp is not installed, install it first:
```bash
brew install yt-dlp  # macOS
# or: pip3 install yt-dlp
```

### Step 2: Get the Transcript

Use the `youtube-transcript` skill (invoke via the Skill tool) to download and clean the transcript to plain text. Follow its full workflow: check subtitles, try manual then auto-generated, convert VTT to plain text with deduplication, fallback to Whisper if needed.

The transcript skill handles VTT-to-text conversion — do not duplicate that logic here. Read the resulting plain text file to get the full transcript.

### Step 3: Generate the Slug

From the video title, generate a kebab-case slug:

```bash
echo "VIDEO_TITLE" | python3 -c "
import sys, re, unicodedata
title = sys.stdin.read().strip()
# Normalize unicode
slug = unicodedata.normalize('NFKD', title).encode('ascii', 'ignore').decode('ascii')
# Lowercase
slug = slug.lower()
# Replace spaces and underscores with hyphens
slug = re.sub(r'[\s_]+', '-', slug)
# Strip non-alphanumeric (except hyphens)
slug = re.sub(r'[^a-z0-9-]', '', slug)
# Collapse multiple hyphens
slug = re.sub(r'-+', '-', slug)
# Trim leading/trailing hyphens
slug = slug.strip('-')
# Truncate to ~60 chars at word boundary
if len(slug) > 60:
    slug = slug[:60].rsplit('-', 1)[0]
print(slug)
"
```

### Step 4: Check for Duplicate Files

Check if the output file already exists. Replace `YYYYMMDD` with the actual date from `date +%Y%m%d` and `SLUG` with the slug generated in Step 3:

```bash
ls /Users/huyphung/workspace/notes/ai-content/YYYYMMDD-SLUG.md 2>/dev/null
```

If the file exists, warn the user and ask whether to overwrite or append a counter (e.g., `YYYYMMDD-slug-2.md`).

### Step 5: Detect Language

Read the transcript and detect the language:
- If the transcript contains predominantly Vietnamese characters/words (diacritics like ă, ơ, ư, ê, ô, đ, or common Vietnamese words), write the summary in **Vietnamese**
- If the transcript is in English, write in **English**
- For all other languages, write in **English**

### Step 6: Summarize the Transcript

Read the full transcript and produce a structured summary following this exact format. Adapt the language based on Step 5.

**Summarization guidelines:**
- **TLDR**: 2-4 sentences capturing the core message
- **Key Concepts**: Terms/concepts specific to the speaker's field and mental model. Do NOT use generic textbook definitions — define each concept as the speaker uses it in their context
- **Main Points**: Capture ALL key ideas/opinions from the speaker. Scale flexibly:
  - Short clips (< 10 min): 2-4 points
  - Medium videos (10-30 min): 4-7 points
  - Long videos (30-60 min): 6-10 points
  - Very long videos (60+ min): 8-15 points
- **Takeaways**: Actionable/valuable insights — what should the viewer learn or do differently after watching

### Step 7: Write the Output File

Get today's date and write to `/Users/huyphung/workspace/notes/ai-content/YYYYMMDD-slug.md`:

```bash
date +%Y%m%d  # for filename: YYYYMMDD
date +%d-%m-%Y  # for frontmatter: DD-MM-YYYY
```

Write the file using this exact structure:

```markdown
---
title: "Video Title"
date: DD-MM-YYYY
tags: [summarized, youtube, tag1, tag2, tag3]
source: YOUTUBE_URL
type: youtube
---

> **Note**: This content was generated by AI. Please double-check against the original video for accuracy.

## Speaker

**Speaker Name** — brief role/context if available from the video

## TLDR

(2-4 sentence summary)

## Key Concepts

- **Concept**: Definition in the speaker's context

## Main Points

### 1. Point Title

Explanation of the speaker's key idea/opinion.

### 2. Point Title

...

## Takeaways

- Valuable insight from the video
- ...

---
*Summarized by Claude*
```

**Frontmatter rules:**
- `tags`: always include `summarized` and `youtube`, plus 3-5 topic tags generated from the content. Tags should be lowercase, single-word or hyphenated (e.g., `machine-learning`, `productivity`)
- `date`: format is `DD-MM-YYYY` (e.g., `29-03-2026`)
- `source`: always the full YouTube URL
- `type`: always `youtube`

### Step 8: Clean Up and Report

Remove temporary files (VTT, transcript_clean.txt) and report the saved file path:

```
Saved summary to: /Users/huyphung/workspace/notes/ai-content/YYYYMMDD-slug.md
```

## Error Handling

- **Transcript download fails**: Inform user with the specific error from yt-dlp
- **Very short video (< 1 min)**: Simplify structure — may skip Key Concepts, reduce Main Points
- **Metadata extraction fails**: Proceed with what's available, use the URL as source
- **Very long video (2+ hours)**: If transcript is extremely large, process in chunks and synthesize. Note this in the output.

## Long Video Handling

For videos over 2 hours, the transcript may be very large. If this happens:
1. Split the transcript into logical chunks
2. Summarize each chunk
3. Synthesize the chunk summaries into the final structured format
4. Add a note: `> This is a long video. Summary was produced from chunked analysis.`
